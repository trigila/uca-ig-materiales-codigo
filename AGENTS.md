# AGENTS.md — Código descargable de Informática General

## Alcance

Este repositorio contiene únicamente ejemplos de código publicados como complemento de materiales IG y herramientas técnicas para administrarlos. El HTML académico es la fuente del contenido; los `.py` se derivan de sus bloques de código y no deben reinterpretar criterios didácticos.

## Reglas

- Descubrir los documentos y ejemplos desde `manifest.json`; no mantener inventarios rígidos en estas instrucciones.
- Mantener nombres `IG.A.NN_EXXX_TIPO.py` sin versiones del PDF. No reutilizar identificadores retirados ni mover archivos publicados sin revisar referencias.
- Conservar UTF-8, cuatro espacios por nivel y ausencia de tabulaciones. No corregir silenciosamente ejemplos `NO_ADMITIDO` ni convertirlos en `ESPERADO`.
- Registrar dependencias de fragmentos en el manifiesto; no inventar datos de prueba para volverlos autónomos.
- No insertar URLs reales en HTML ni completar enlaces del manifiesto antes de contar con la publicación autorizada y validada.
- No guardar rutas absolutas, tokens ni credenciales.
- No publicar, eliminar ni modificar contenido remoto sin autorización explícita.

## Verificación

Antes de preparar una publicación, ejecutar las herramientas de validación. Para un HTML con enlaces, generar una copia de prueba, exportar el PDF con Chrome y comprobar visualmente páginas, anotaciones de enlace y la descarga real del archivo correcto.
